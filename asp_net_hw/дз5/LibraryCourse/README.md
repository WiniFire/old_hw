# Учёт библиотеки

Курсовой проект по ASP.NET Core MVC.

Приложение предназначено для библиотекаря. В нём можно вести каталог книг и список читателей, оформлять выдачу и возврат, просматривать историю и просроченные выдачи.

## Запуск

Нужен .NET SDK 10. Открыть `LibraryCourse.sln` в Visual Studio либо запустить `start.bat` в папке проекта. При первом запуске пакеты NuGet восстанавливаются автоматически, поэтому может понадобиться интернет.

Адрес: http://localhost:5085

Логин: `admin`, пароль: `Library123!`.

SQLite создаётся автоматически в `App_Data/library.db`. При первом запуске добавляются пять книг, два читателя и одна просроченная выдача для проверки интерфейса. Изменения сохраняются после перезапуска. Для новой базы при остановленном приложении можно удалить папку `App_Data`.

## Возможности

- Вход библиотекаря и выход из учётной записи.
- Добавление, редактирование и удаление книг и читателей.
- Поиск по названию и автору без учёта регистра, фильтр по жанру.
- Проверка обязательных полей, email, телефона и числовых значений.
- Выдача только свободных экземпляров, запрет повторной выдачи той же книги одному читателю.
- Возврат книги и сохранение истории.
- Фильтры активных, просроченных и завершённых выдач.
- Краткая статистика на главной странице.

Книги и читатели с историей выдач не удаляются. Количество экземпляров нельзя уменьшить ниже количества книг на руках. Срок выдачи — до 90 дней.

## Структура

`Models` — сущности и модели форм. `Data` — контекст EF Core и начальные данные. `Controllers` — обработка запросов. `Services` — проверка и оформление выдачи. `Views` — страницы Razor. `wwwroot` — оформление.

Используются ASP.NET Core MVC, Entity Framework Core и SQLite. Связи: книга имеет много выдач, читатель имеет много выдач. Пароль хранится в базе как хеш. Доступ к разделам закрыт атрибутом Authorize, POST-формы защищены antiforgery-токенами.

## Проверка работы

1. Войти и открыть каталог.
2. Добавить книгу и читателя, изменить их данные.
3. Найти книгу по части названия и по автору.
4. Выдать книгу, проверить уменьшение доступного количества.
5. Попробовать выдать эту же книгу тому же читателю ещё раз.
6. Оформить возврат и открыть раздел «Возвращены».
7. Перезапустить приложение и проверить сохранение данных.

Это локальное учебное приложение. Регистрация новых сотрудников и публичное развёртывание в данной версии не предусмотрены. Учётная запись для демонстрации задаётся в appsettings.json и создаётся при первом запуске.
